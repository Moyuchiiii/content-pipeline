- **Thread内の「山場」が伸びる**: Mar29予約システムthread「詰まった箇所は2つ」108impでthread内トップ。Hook→展開→山場の構造が機能している

### 課題

- **Apr9 グラフ投稿15imp**: 「Claudeに〜って言うだけで」の曖昧訴求。具体的な時短数字なしはリーチしない
- **Apr7 /loop投稿18imp**: 「ほぼゼロになった」曖昧表現。Apr4「週5h→2h」との差は数字の具体性
- **速報系はいいね0傾向**: Apr1 Computer Use 81imp / Apr2 /powerup 44imp / Apr23 Pro A/B 29impいずれもいいね0。認知は取れるがエンゲージに繋がらない
- **URLクリック未計測**: TypefullyのlinkClicksがnull多数。リプライ設置URLの効果検証不能

### 次回記事への示唆

- 次のX施策は「スキ数引用+具体的Before/After」の組み合わせ（実績型×体験型のハイブリッド）
- 「ほぼゼロ」「劇的に」等の曖昧表現を禁止。必ず数字（分・時間・金額）を入れる
- 速報投稿は単独ではなくnote誘導とセットで評価（リーチだけ取れれば可）
- メイン商品CTA記事Apr14のパターン（実績数字→失敗→転換点の流れ）を他ツイートにも応用
