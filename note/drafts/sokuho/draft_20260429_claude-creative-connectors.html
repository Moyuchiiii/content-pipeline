Adobeの案件、Canvaの案件、毎回ツールを行ったり来たりしていませんか？

4月28日（米国時間）、Anthropic が「Claude for Creative Work」を発表した。

Adobe Creative Cloud、Blender、Autodesk Fusion、SketchUp、Affinity by Canva、Ableton、Splice、Resolume Arena/Wire ── クリエイティブ業界の主要ツールが、Claude から直接動かせるようになった。

Anthropic 公式（@claudeai）の発表は短時間で 3.4万いいね・704万閲覧。

クリエイティブ系副業者のXタイムラインは、4/29 朝はだいたいこれの話で持ち切りだった。

ただ、note 側の記事はまだ「機能解説」に寄っていて、「で、これ副業の現場でどう使えるの？」って整理は意外と少ない。

文系大学生で、Claude依存度高めで副業4ヶ月目のわたしから、現場視点で何が変わるかだけ整理しておく。

何が発表されたのか、まず公式の事実だけ

4/28 に発表されたのは、クリエイティブツール9連携と、Blender 開発基金への支援。

連携先はこの8カテゴリ。

Adobe Creative Cloud
Photoshop、Premiere、Illustrator、Lightroom、Express、InDesign、Adobe Stock など 50+ ツール。Claude から自然言語で指示して画像編集・動画リサイズ・デザイン生成。
Affinity by Canva
バッチ画像調整、レイヤー名の整理、ファイル出力の自動化。Canva 既存デザインの一括リサイズや、ブランドテンプレートへの自動流し込み。
Blender
Python API への自然言語インターフェース。シーン全体のデバッグ、複数オブジェクトへの一括変更、未使用データのクリーンアップ、新ツールの自作スクリプト。
Autodesk Fusion
会話で 3D モデルの作成・修正。エンジニアじゃなくても「ここをこう変えて」が通る。
SketchUp
会話から 3D モデリングの叩き台を生成。建築・インテリア系の最初の一手。
Ableton
公式ドキュメントを基盤にした回答。DAW のクセを Claude が説明してくれる側。
Splice
ロイヤリティフリーの音源サンプル検索を Claude 経由で。
Resolume Arena / Wire
ライブパフォーマンス向けのリアルタイム制御。VJ・映像演出系。

Resolume が Arena と Wire の 2 系統あるので、ツール単位で数えると 8、コネクタ単位で数えると 9 になる。

もうひとつ大きいのが、Anthropic が Blender 開発基金（Blender Development Fund）に Corporate Patron として参加したこと。

年間最低 €240,000（約 $281,000、約 4,500 万円前後）を Blender に寄付する。

これ、地味だけど結構効く話で。Blender はオープンソースで、企業が自分の AI に閉じ込めずに「LLM 全体が叩ける API」として残してもらう構図になってる。Anthropic 1社の囲い込みじゃない設計を金で支えてる、ってこと。

あと教育機関も同時に組まれてて、RISD（ロードアイランド・スクール・オブ・デザイン）、Ringling College、Goldsmiths University London の 3 校でカリキュラム連携。

「クリエイティブ × 計算」の世代を学校から育てる気でいる。

9連携、副業者の目線で「何ができるようになったのか」

ここからが本題。「Photoshop が Claude から動かせる」って聞いて、副業のあなたは何を想像しましたか？

わたしが副業で受ける案件をベースに、3グループに分けて整理する。

1. クリエイティブ副業（Adobe Creative Cloud）

クラウドワークスで一番案件数が多いゾーン。

具体的には、画像のリサイズ・色調補正・テキスト差し替え・バナー量産・サムネ修正・動画のリサイズ・字幕入れあたり。

これまでの副業フローはこう。

これまで
Claude（or ChatGPT）で構成案 → Photoshop / Premiere を手で開く → 1個ずつ手動で作業 → 書き出し → 納品

Adobe コネクタが入ると、ここの真ん中の「手動で作業」が「Claude に喋るだけ」になる可能性がある。

たとえば「この 30 枚のバナー、ロゴだけ B 版に差し替えて 16:9 と 9:16 で書き出して」って言うと、Claude が Photoshop にコマンドを流して進める、みたいな世界。

正直、これが本当に成立するなら、バナー量産系の単価は崩壊する。

逆に、構成判断・コピー・色味の最終調整みたいな「人の判断が要る部分」は残る。

副業者は「手作業」じゃなくて「判断・指示」の側に乗り換えないと厳しい。

2. デザイン副業（Affinity by Canva）

Canva 案件、最近増えてるじゃないですか。SNS用テンプレ作成、プレゼン資料、軽めのLP叩き台。

Affinity by Canva のコネクタは、既存デザインの「一括リサイズ」「ブランドテンプレへの流し込み」「レイヤー整理」あたりが主戦場。

これ、わたし自身もうれしい話で。

クライアントから「このスライド、A4 の縦長と SNS 用 1:1 と 9:16 の3バージョンで欲しい」って言われた時、いつも「了解しました」と言いながら裏で30分泣いてる。

そこが「リサイズして、テキストだけ各サイズに最適化しといて」で済む可能性がある。

Claude × Canva 連携自体は前から話題で、note でも npaka さんや松尾さん、ウミノさんが先行解説を書いている。Affinity 側も入ったことで、デザインデータの編集権限が一段深くなった、ってのが今回の差分。

3. 3D・映像・音楽副業（Blender / Fusion / SketchUp / Ableton / Splice / Resolume）

正直に言うと、ここはわたしの主戦場じゃない。動画副業や 3D 案件はやってない。

でも、副業の知り合いで Blender やってる人、Fusion で 3Dプリント受託やってる人、Ableton で BGM 作ってる人がいるので、その人たち目線でだけ整理しておく。

Blender に関しては、Anthropic が「Python API への自然言語インターフェース」って言い方をしてるのが地味にデカい。

Blender ってめちゃくちゃ機能が多くて、「アドオン作ろうとして 1 週間詰む」みたいな話を聞く。そこを「Claude にやりたいことを伝えるだけで Python スクリプトが書ける」になるなら、Blender 案件の単価感は変わる。

Fusion / SketchUp も「会話で 3D モデルを叩く」が公式の打ち出し。3Dプリント受託、CAD 系副業、建築インテリアの素案出しが対象になる。

Ableton / Splice / Resolume は音楽・映像演出の世界。Splice の「ロイヤリティフリー音源を Claude 経由で検索」あたりは、SNS用 BGM 探しの時短に直結する。

クリエイティブ副業の単価は、これから「ツールを動かす技術料」より「何をどう動かすかの判断料」にシフトしていくと思う。

その移行期に、ちょっと先に副業始めた立場から書いた全記録を置いてあるので、よかったら覗いていって。

正直に言うと、わたしはまだ全部触ってない

ここまで書いておいて何だけど、9連携を全部触ったわけじゃない。

4/28 米国時間の発表で、日本側にきれいに届いたのが 4/29 朝。Adobe Creative Cloud は Adobe 側のロールアウトに合わせて段階的、Blender / Fusion はコネクタの初期セットアップが要るし、Resolume / Splice / Ableton は環境を持ってない。

触らないで「現場が変わる」って書くのも違うので、現時点でのスタンスだけ正直に置いておく。

すぐ触る
Affinity by Canva（既存案件で即試せる）、Adobe コネクタの Photoshop / Express 部分（バナー量産案件で再現実験）
来週触る
Blender コネクタ（副業の知り合いに付き合ってもらって試させてもらう想定）
当面触らない
Fusion / SketchUp / Ableton / Splice / Resolume（環境持ってないし、副業の主戦場じゃないので、自分で語るんじゃなくて触ってる人の発信を読みに行く側）

触ってないのに「これは革命です」って書く速報、note にも X にもめちゃくちゃあるけど、副業初心者がそれを真に受けると詰むやつなんだよね。

「公式が何を出したか」「自分は何を試した／試してない」を分けて書くのが、結果的に読者の判断の助けになると思ってて。

note の先行記事と、わたしの役割の住み分け

note を「Claude Connectors」で検索すると、すでに先行記事が並んでる。

npaka さんの「Blender・Autodesk・Adobe とつながる Claude の新 Connector」は、リリースの全体像を一番早くまとめてた。「Claude の Adobe for creativity の使い方」「Blender Connector の使い方」も同氏。機能解説の信頼性は突き抜けてる。

松尾さん、ウミノさんは Canva 連携を中心に、デザインワークフローの組み替え方を書いている。

その上で、わたしが書ける角度はひとつだけ。

「クリエイティブ副業者の目線で、9連携で何が変わって、何は変わらないか」

機能の正確な解説は、それぞれの先行記事の方が詳しいし、わたしより試してる人の発信を読んだ方が早い。

わたしの役割は、副業の現場で「これ案件単価にどう効くか」「自分の作業フローのどこを差し替えるか」「触る順番はどこからか」を、文系大学生の目線で整理する側。それ以上は出ないようにする。

同じ場所で詰まってる君へ、3つだけ置いていく

クリエイティブ副業に AI を組み込もうとしてる、これから始める君に、ちょっと先に試した立場から3つだけ。

1. Adobe / Canva 連携は「いま触れる人から触る」が正解。バナー量産・スライドリサイズ系の案件は、確実に作業時間が変わる側。順番としては、Affinity by Canva → Adobe Express → Photoshop の順で重さを上げていくと挫折しにくい。

2. 3D・映像・音楽コネクタは、自分の主戦場じゃないなら無理に触らない。SNS で「すごい」が流れてくるだけで、案件に直結するとは限らない。「このコネクタが副業案件のここを変える」が言えるまでは、触ってる人の発信を読む側でいい。

3. 「Claude に動かしてもらう前提」で案件の単価を見直す。バナー1枚 500 円のような単純作業案件は、これから単価が下がる側。逆に「ブランドガイド込みで一括処理してください」みたいな判断付きの依頼は、むしろ単価が上がる。受ける側の目線も、いま少しずつスライドさせておくのが安全。

これだけで、わたしが「Adobe コネクタが出た日に何を最初に触ればいいか」で30分くらい固まってた時間は飛ばせる。

クリエイティブ副業のフローが今日からじわじわ書き換わる。明日からの 1 週間で、わたしが Affinity by Canva と Adobe Express を実際に副業案件に当ててみた話を、また別の記事にまとめる予定です。

9連携が全部出揃ったタイミングで「で、副業 2 ヶ月で月 14 万まで来るときに、わたしは何を試して何を捨てたのか」を全記録で置いてあります。
