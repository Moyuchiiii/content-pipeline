# SpaceX提携でClaude Codeのレートが2倍になった日｜Pro月3000円のわたしが変わったこと

## 冒頭アイランド問いかけ
Claude Pro 月3000円、5時間制限で止まったことありませんか？

## 導入
朝、Claude Code に向き合って2時間。気づいたらレートリミットに当たって、午後はブラウザ版に逃げる。そんな日がわたしのClaude Pro 副業の標準だった。

2026年5月6日（米国時間）、それが変わった。

Anthropic が SpaceX と組んで、Claude Code の5時間制限を2倍にした。Pro/Max ユーザーのピークアワー制限も外した。

月20ドル払ってる文系大学生として、何が変わったかを記録する。

## h2-1: 5/6発表「SpaceXと組んでClaude Codeを2倍にした」って何が起きたの

公式: https://www.anthropic.com/news/higher-limits-spacex

- Claude Code 5時間レートリミット 2倍化（Pro / Max / Team / seat-based Enterprise）
- ピークアワー制限の撤廃（Pro / Max）
- Opus API レートリミット 引き上げ（公式表現は「considerably」）

すべて 2026年5月6日付（米国時間）で即時有効。日本時間でいうと7日朝に反映。

背景: SpaceX との計算インフラ提携。Colossus 1 データセンターから 300メガワット超、NVIDIA GPU 22万基相当を1ヶ月以内に増設。

## h2-2: わたし、月20ドル(¥3,000)のPro派なんだけど、何が変わるの

結論: 5時間で止まる恐怖から解放された。

Before（5/6まで）: 朝2-3時間 → レートリミット → 午後 reset 待ち or ブラウザ版に切替え
After（5/7以降）: Pro 月20ドルで5時間枠が10時間相当に

ピークアワー制限撤廃: 米国時間の混雑帯（日本時間の夜帯）が Pro/Max で絞られていたのが解消。副業大学生にとって22時以降の作業が普通に回る。

実質「Maxプランの一歩前」の枠が手に入った感覚。
