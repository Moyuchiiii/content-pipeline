ITmedia の速報によると、AI が自分でコードベースを丸ごとスキャンして脆弱性を見つけ、パッチまで提案するツールらしい。Opus 4.7 ベース。

でも、わたしの Claude Pro $20/月の契約には来ない。

これは Claude Enterprise 向け。

@claudeai の3連スレッドを読んで、まず思ったこと

Claude Security is now in public beta for Claude Enterprise customers.
Claude scans your codebase for vulnerabilities, validates each finding to cut false positives, and suggests patches you can review and approve.

ひとつめ。

これから「AIが書いた納品物にAIで脆弱性スキャンかける」が、エンプラ案件の標準になる流れだから。

クラウドワークスのAI関連案件、5,832件あって、Web系・スクリプト系で「セキュリティ意識した実装」を案件詳細に書いてるクライアントがじわじわ増えてる気がする。法人クライアントが「AI使って作った成果物、ちゃんとチェックしてあるんだよね？」を求める時代に入ってきた、ってこと。

ふたつめ。

Anthropic 公式ブログ（4/30米国時間）にはTeam / Max プランにも「近いうちに」展開予定って書いてある。Pro プランへの展開はリリース文では明示されていない。

つまり、Max ($100/月) で副業してる人にはたぶん半年〜1年で降りてくる。Pro $20 はまだ別ラインの可能性あり。

副業の納品物の品質保証、何が変わるか整理してみた

「Claude Security は個人には来ない」と頭ではわかってる。けど、この流れは副業者の現場にじわじわ効いてくる。

現時点で予想してる変化は3つ。

Before
「動けばOK」「テスト通ってればOK」で納品できた小規模案件
After
「AI で生成した部分にAIで再点検しました」が標準になる可能性

あなたが今クラウドワークスで請けてる案件、Claude Code でガッと書いてそのまま納品してませんか？

わたしは正直、書いてた。

Excel マクロ案件で「動作確認しました、納品します」って投げて終わり、みたいなフローが多かった。

でもこれから「AIで生成したコード、AIで点検済み」を当たり前に求められる気がしてる。エンプラ向けに普及したものは、半年遅れで小規模案件にも基準が下りてくる。SEOがそうだったし、アクセシビリティもそうだった。

Team / Max への順次提供は『近いうちに』、Pro は明言なし

Anthropic 公式リリース文には「Access for Claude Team and Max customers is coming soon」と書いてある。一方で Pro プランへの提供時期は記載されていない。

「Coming soon」が3ヶ月なのか半年なのかはわからない。けど、Pro プラン($20)に降りてくるかは現時点で明言ナシ。

個人的な予想は、Max ($100/月) 止まり。Pro まで降ろすと「Anthropic がコードレビューSaaS化した」みたいになって、Anthropic の戦略上たぶん別商品ラインとして切り出してくる。

つまり、わたし含む「Claude Pro $20 で副業してる勢」は、しばらく自分のチェックリストを Claude に通す運用で乗り切る必要がある。

同じ場所で詰まってる君へ、3つだけ置いていく

5月1日時点で Claude Pro $20 派の副業者ができることを、3つだけ整理して置いていく。

1. Claude に「セキュリティレビュー観点で読んで」って投げる癖をつける。納品前の最終チェックに1往復だけ挟む

2. クライアント案件で「AIで作ったコード」を渡すときは、自分で「OWASP Top 10 観点でレビューして」のプロンプト1個用意しておく

3. Anthropic の Pro/Max プラン展開を月1で確認。降りてきたら速攻で副業フローに組み込む

これだけで、Claude Security が降りてくる前の数ヶ月で、納品物の見え方は変わる。わたしが今日「諭吉100万」を遠目に眺めてちょっと焦ったあの時間は、これで君は飛ばせる。

セキュリティの話を書いておいて何だけど、わたしが副業始めたばかりの頃は「動くコード書く」だけで精一杯だった。そこから2ヶ月で月14万に来た記録は、メイン記事に納品物の作り方含めて全部書いてある。
