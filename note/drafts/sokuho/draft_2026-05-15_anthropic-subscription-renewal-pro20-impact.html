Anthropic がサブスク変えるって聞いて、あなたの副業に影響あるか焦っていませんか？

5月14日に Anthropic がサブスクの仕様変更を発表した。

「6月15日から Claude Pro が実質値上げ」みたいな見出しが流れてきて、わたしも一瞬ドキッとした。

結論から書く。

Pro $20 で Claude Code を毎日使ってる副業派は、ほぼ何も変わらない。

でも、人によっては変わる。

その境目を、わたしの副業フローに照らして整理しておく。

Anthropic 6/15刷新、何があったか

公式ヘルプセンターに掲載されてる内容をそのまま書く。

変更の中身
6月15日から Agent SDK と claude -p（非インタラクティブモード）の利用が、月次クレジット別枠になる

月次クレジットの金額はプランごとに決まってる。

付与額（プラン別）
Pro $20 / Max 5x $100 / Max 20x $200 / Team Standard $20 / Team Premium $100 / Enterprise $20〜$200

未使用分は翌月に繰り越されない。

超過したら標準API料金で課金される（事前に extra usage を有効化した場合のみ）。

これだけ聞くと「Pro $20 って今までと同じ料金なのに、Agent SDK使うと別枠で消費される＝実質値上げ」に見える。

でも、ここに大事な区別がある。

わたし（Pro $20 派）が「変わらない」ところ

公式の対象外リストを見ると、こう書いてある。

クレジット対象外（=従来のサブスク枠内のまま）
ターミナル/IDE で動かす Claude Code・Claude.ai のチャット（Web/Desktop/Mobile）・Claude Cowork

これ、わたしの副業フローまんま。

普段やってるのは Claude Code をターミナルで起動して、案件のコード書かせて、納品物作って、終わり。

これは「Interactive Claude Code」に分類される。

つまり、わたしの $20 はそのまま $20 で、weekly limit も従来通り使える。

6/15 以降も体感ゼロ。

ちなみに先週、ClaudeDevs 公式から「Claude Code weekly limits +50%、7/13まで」が告知されてる。

むしろ枠が増えるタイミングだったりする。

一部の人だけ変わる、Agent SDK 別枠の話

公式の対象リストを見ると、ここに該当する人は影響を受ける。

クレジット対象（=月次別枠で消費）
Claude Agent SDK を Python / TypeScript であなたのプロジェクトに組み込んでる・claude -p コマンド（バックグラウンド処理）を使ってる・Claude Code GitHub Actions を回してる・OpenClaw や Conductor などサードパーティ製エージェントを使ってる

これらは「プログラムから Claude を呼ぶ」用途。

副業初心者の段階だと、まず触らない領域。

でも、慣れてきて「夜寝てる間に Claude にPR作らせる」「GitHub Actions で自動レビュー回す」みたいなことを始めると、ここに該当してくる。

その時に $20 の月次クレジットで足りるかどうか、なんだよね。

足りなければ、超過分は standard API rate で課金される。

これは「プロンプトキャッシュ最適化されてない使い方だと、月数百ドル〜数千ドル飛んでた」という4月の事件への対応策でもある。

4月上旬、Anthropic は OpenClaw 等のサードパーティ製エージェントを全面禁止してた。

それが今回、$20 別枠 + 超過は API 課金、という仕組みで解禁された形。

ちなみに、月14万まで来た副業フローはぜんぶ Claude Code interactive で完結してて、Agent SDK は1度も触ってない。「副業初心者は interactive で十分」の根拠みたいなのは、ここのメイン記事にまとめてある。

あなたのフローは、どっち側か3秒で確認できる

「自分が Agent SDK 使ってるかどうか、わかんないかも」と思ったら、3秒で確認できる。

確認方法
ターミナルで claude を打って起動してる→ interactive（影響なし）・claude -p "プロンプト" の形で打ってる→ Agent SDK扱い（影響あり）・OpenClaw / Conductor / 自作スクリプトから Claude を呼んでる→ Agent SDK扱い（影響あり）

わたしの場合、ぜんぶ前者だった。

CW案件のコード書くのも、note記事の下書き作るのも、claude を打って対話しながら進めるスタイル。

そもそも、副業初心者が Agent SDK で自動化を組むのは、現場の流れ的にも早い。

まずは Claude Code を手で触って、案件を1件取って、納品して、を繰り返すフェーズが先。

自動化は、その繰り返しが面倒になってきた頃にやればいい。

同じ場所で焦ってる君へ、3つだけ置いていく

1. claude -p や GitHub Actions を使ってないなら、6/15 は何も変えなくていい。情報を眺めて終わり

2. 「自分は Agent SDK 使ってるかも」と不安なら、ターミナルで打ってるコマンドを見直す。claude だけなら影響なし

3. 副業初心者で焦ってるなら、Agent SDK は後回し。interactive Claude Code を毎日触る方が圧倒的に近道

これだけで、わたしが昨日 X のタイムラインで「Pro $20 値上げ！？」を見て一瞬焦った時間は飛ばせる。

稼ぐ前にツールの仕様で迷うのが一番もったいない。Claude Code を手で触って案件1件取る、までの流れはここに全部書いた。
