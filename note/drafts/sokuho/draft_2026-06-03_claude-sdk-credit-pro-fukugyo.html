Claudeの月¥3,000、自動化に使ってる人いますか？

わたしのClaude Pro、毎月¥3,000払ってる。

そして6月15日、その¥3,000の使い方がちょっと変わる。

5月の半ばにAnthropicが発表した内容を見たとき、いったん作業の手を止めた。

6/15から、Claude Codeの使い方が二つに分かれる

Anthropicが2026年5月14日に発表したのは、こういう話だった。

Claude Codeの使い方を「対話的に使う部分」と「プログラムから動かす部分」に分けて、後者だけ別枠のクレジットで管理することにする、という変更。

対話的というのは、ターミナルやIDEから直接話しかけて作業する使い方。これは6月15日以降も、Pro ¥3,000の枠の中で従来通り使える。

変わるのは、プログラムから動かす方。具体的にはこの4つが対象になる。

claude -p コマンド
Claude Codeを非対話モードで動かすときに使う
Claude Agent SDK
自分のアプリから Claude を呼び出して動かす
Claude Code GitHub Actions
GitHubのワークフローに組み込む
Agent SDK経由のサードパーティアプリ
外部ツールが Claude のサブスクで認証される場合

これらが、6月15日から月次のクレジット枠で動くようになる。Pro なら $20相当、Max 5x なら $100、Max 20x なら $200。月次リセットで、未使用分は翌月に持ち越せない。

サブスク自体は値上げじゃない。あくまで「自動化で使ってた分が、別の枠に切り出された」っていう感じ。だから、人によって「実質値上げ」にも「実質増量」にも見える。

自分が「自動化派」かどうか、まず確認する

ターミナルを開いて、Claude Codeに直接話しかけて作業してるだけの人は、影響ゼロ。¥3,000の中で従来通り使える。

でも、こういう使い方をしてる人は別枠の話に該当する。

夜寝てる間に Claude Code をスケジュール実行させてる人。GitHub Actions に Claude を組み込んでる人。自分のアプリから Claude API 経由で呼んでる人。

わたしは後者だった。

noteの記事生成も、案件チェックの自動化も、claude -p コマンドでバッチ処理させてる。週5時間が40分になったのも、これがあったから。

自分がどっちか分からない時は、Claude Code で /usage って打つと、直近の消費量が見える。そこにプログラム経由の利用が含まれてたら、6/15の話が自分にも来る。

ちなみに、わたしが Claude Code を「自動化派」として使い倒すまでの2ヶ月の作業ログは、こっちのメイン記事にぜんぶ書いた。応募文の書き方も、案件のジャンル移動も、ぜんぶ込み。

わたしが6/15までにやること

6月8日に Anthropic から案内メールが届く予定らしい。そこにクレジットの請求方法が書いてある。

やることは3つだけ。

1つ目は、案内メールが来たら Anthropic の設定画面で claim ボタンを押す。これを忘れると、6/15以降の自動化フローが止まる可能性がある。

2つ目は、自分が動かしてる自動化を棚卸しする。note生成・案件スキャン・GitHub Actions、どれが claude -p / SDK 経由で動いてるかを書き出す。

3つ目は、月次クレジットを使い切ったときの行動を決めておく。追加で API 課金を有効化するのか、その月は停止して翌月待つのか。決めておかないと、月末に焦ることになる。

同じ場所で詰まってる君へ、3つだけ置いていく

1. 6月8日のメールが来たら、Anthropic Settings から claim ボタンを押すのを忘れない

2. 自分の Claude Code 使い方が「対話だけ」「自動化も使ってる」のどっちかを棚卸ししておく

3. 月¥3,000の使い分けを意識する習慣をつける。自動化用の $20と、対話用のサブスク枠を別物として扱う

これだけで、わたしが「結局なに変わるんだ」のモヤモヤに使った半日は飛ばせる。

料金の話と稼ぎ方の話は、いつもセットになる。月¥3,000の使い方が変わるなら、稼ぎ方の側もアップデートが要る。わたしの2ヶ月のアップデートはこっちに全部詰めた。
