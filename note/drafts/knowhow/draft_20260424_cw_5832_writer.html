クラウドワークスの「AI案件」を検索してみて、ライター系ばかり出てきませんか？

副業を始めようと思ってクラウドワークスに登録したとき、最初に大量に出てきたのが「AIライター」案件だった。

1文字0.3円、1記事3,000文字で900円。時給換算すると300円を切る案件もざらにある。

「AI副業ってこんなもんなの？」って諦めかけたこと、ある人多いと思う。

わたしもそうだった。最初の2週間は本気でそう思ってた。

でも2ヶ月後、わたしは月14万円稼ぐようになってた。選んだのはライター案件じゃない。

クラウドワークスのAI案件5,832件、その内訳を見直したら全然違う世界が見えた話を書く。

クラウドワークスのAI案件、2026年に5,832件超になってた

まず数字を出す。2026年4月時点で、クラウドワークスの「AI関連案件」は累計5,832件を超えてる。

2023年11月から2024年にかけて、生成AI関連の契約件数は前年比8.4倍に急増した。さらに、AI案件の単価は1.8倍に上昇してる。

クラウドワークスAI案件の成長率
件数 2024年比 8.4倍／単価 1.8倍／2026年累計 5,832件超

もう一つ大事な数字がある。

生成AIを副業で使っている人の年間副収入は平均119.1万円。使ってない人の約2倍。月換算で約10万円の差がついてる。

これだけ見ると「AI副業チャンスでは？」と思う。

実際チャンスではある。ただ、5,832件の中身を見ると、全部が全部「非エンジニアの副業初心者」に向いてる案件じゃない。

ここを見落とすと、文字単価300円のAIライター地獄に突っ込む。

5,832件の内訳は、実はライターばかりじゃない

クラウドワークスで「AI」を検索すると、上位に出てくるのは確かにライティング案件が多い。でも実際の内訳をざっくり分解するとこうなる。

① AIライティング（3,000件以上）
ブログ記事・SEO記事・要約。単価0.3〜1円の激戦区。AI利用前提でも報酬は据え置きが多い
② 業務自動化スクリプト（増加中）
Excel マクロ・スプレッドシート連携・Python 小規模ツール。単価1万〜6万円、競合が少ない
③ WebアプリUI／LP 制作（AI活用型）
ランディングページ・管理画面・予約システム。単価3万〜10万円、Claude Code と相性が良い
④ ChatGPT プロンプト作成・カスタムGPTs
企業向け AI 設計代行。単価5千〜3万円、増加トレンド
⑤ データ分析・リサーチ代行
市場調査・競合分析・レポート作成。単価1万〜5万円

全部ひっくるめて5,832件。そのうち半分以上は①のライティング系で、競合が集中してる。

逆に言うと、残りの約2,800件は競合がそれほど激しくない。

文系大学生で、プログラミング経験ゼロのわたしが選んだのは、意外にも②と③だった。

文系大学生のわたしが実際に選んだのは「業務自動化」だった

ここで一度整理する。

わたしはプログラミング経験ゼロ。情報系の大学に通ってるわけでもない。バイトでカフェ店員やってた普通の大学生。

そのわたしが「業務自動化スクリプト」案件に応募した理由は3つある。

理由1 単価が段違いに高い
AIライター0.3円／字に対して、業務自動化は1件1万5千円〜6万5千円。1件で文字数系の何日分にもなる
理由2 継続案件につながりやすい
一度動くものを納品すると、改修・追加機能で継続依頼が来る。ライターは単発で終わりやすい
理由3 Claude Code との相性が最高だった
「この処理を自動化したい」を日本語で伝えるだけで、コードを Claude Code が書いてくれる。文系でも動かせる

結果として、業務自動化3件 + WebアプリUI案件1件で、2ヶ月目に月14万円に到達した。

実際に受注した案件の金額を並べるとこうなる。

2ヶ月目の受注内訳
Excel 業務自動化 ¥18,000／予約管理システム ¥30,000／管理画面UI ¥45,000／LP 改修 ¥47,000

合計14万円。月4件ペース。文字単価0.3円のライター案件で同じ金額を稼ごうとしたら、約466,000文字書く必要がある。計算上は不可能じゃないけど、時給換算で考えると現実的じゃない。

ちなみに、副業ゼロの文系大学生がなぜ2ヶ月で月14万に到達できたのか、使ったプロンプトや応募文テンプレをまとめた全手順記事を別で書いてる。この記事の後半の「応募文の書き方」部分は、そっちに全テンプレ載せた。

文系でも業務自動化案件が取れた理由

「でも、業務自動化ってコード書けないと無理じゃない？」って思う人いると思う。

わたしも最初そう思ってた。

でも実際にやってみたら、コードを「書く」場面ってほぼなかった。代わりにやってるのは「AIに頼む」「出てきたものを確認する」だけ。

たとえば Excel の業務自動化案件。クライアントは「売上データを自動集計して、毎週月曜にメールで送信したい」という依頼を出してくる。

わたしのやり方はこう。

Step 1 案件詳細を Claude にコピペする
「この案件をわたしが受注するとしたら、何を確認すべきか・要件を5つ整理して」と頼む
Step 2 AI が整理した要件をクライアントに確認する
「こういう認識であってますか？」と Claude が作った確認文をそのまま送る
Step 3 Claude Code に実装を指示する
「Google Apps Script でこの要件を満たすコードを書いて」と日本語で頼む
Step 4 出てきたコードを動作確認して納品
実際に動くか検証。動かなかったら「ここでエラーが出た」を Claude Code に伝えて直してもらう

ここでわたしがやってるのは、「依頼内容を理解してクライアントと会話する」と「動作確認をする」の2つだけ。

コードを書いてるのは Claude Code。わたしは「こう動いてほしい」と日本語で伝えてるだけ。

Claude Code は、Anthropic が作った AI で、チャット感覚で指示するとコードを書いたり作業を自動化してくれるツール。インストールは最初の1回だけで、あとはコピペでいい。

AI時代の副業で求められるスキルって、コードが書けることじゃなくて「AIに頼めて、出てきたものが合ってるか判断できる」ことだと思う。

それなら、文系でもできる。

ライター以外の案件を見つけるコツ

じゃあ実際、どうやって②〜⑤の案件を見つけるのか。わたしが使ってる検索キーワードをそのまま公開する。

業務自動化系を探すキーワード
Excel 自動化／Google Apps Script／Python スクリプト／業務効率化／データ集計
Webアプリ・LP系を探すキーワード
LP 制作／管理画面／予約システム／フォーム作成／ダッシュボード
プロンプト・GPTs系を探すキーワード
ChatGPT プロンプト／カスタムGPTs／AI 設計／プロンプト開発

これに加えて、フィルターで「AI利用OK」「ChatGPT可」を有効にしておくと、AI 使用を公言できる案件が出てくる。

さらにコツがある。

予算1万円以上で絞ると、低単価のライター案件がほぼ消える。案件の質が一気に上がる。

もう一つ。「継続案件になりそうな案件」を優先する。

案件本文に「改修できる人を募集」「月額契約応相談」「今後も継続して依頼したい」という文言が入ってる案件は、1件納品した後に継続依頼に化ける確率が高い。わたしの継続率は6割超えてる。

まとめ

クラウドワークスの「AI案件5,832件」と聞くと、チャンスがありそうに見える。

実際、チャンスはある。ただし、検索結果の一番上に出てくる「AIライター0.3円／字」の世界に飛び込むと、時給300円のループから抜けられなくなる。

5,832件の内訳を角度別に見て、自分の強みと合う領域を選ぶ。これだけで世界が変わる。

文系のわたしの場合、選んだのは業務自動化と WebアプリUI。理由は単価が高くて、継続案件になりやすくて、Claude Code との相性が良かったから。

非エンジニアでも AI 副業で稼げる。ただ「AIライター」という入口だけを見てると、その可能性に気づけない。

検索キーワードを変えてみるだけで、見える案件は全然違う。

2ヶ月前のわたしに教えたい。ライター案件で消耗する前に、業務自動化を見に行け、と。

2ヶ月前の状態から月14万円に到達するまでの全工程、応募文テンプレ3パターン、CLAUDE.md の設定ファイル、実際に受注した案件3件のケーススタディを全部載せた完全ガイドはこっちに書いた。稼ぎ方の全体像を最短で掴みたい人向け。
