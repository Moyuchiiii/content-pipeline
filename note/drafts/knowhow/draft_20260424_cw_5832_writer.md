# CWのAI案件5,832件、文系大学生が選んだのはライターじゃなかった

---

**クラウドワークスの「AI案件」を検索してみて、ライター系ばかり出てきませんか？**

---

副業を始めようと思ってクラウドワークスに登録したとき、最初に大量に出てきたのが「AIライター」案件だった。

1文字0.3円、1記事3,000文字で900円。時給換算すると300円を切る案件もざらにある。

「AI副業ってこんなもんなの？」って諦めかけたこと、ある人多いと思う。

わたしもそうだった。最初の2週間は本気でそう思ってた。

でも2ヶ月後、わたしは月14万円稼ぐようになってた。選んだのはライター案件じゃない。

クラウドワークスのAI案件5,832件、その内訳を見直したら全然違う世界が見えた話を書く。

## クラウドワークスのAI案件、2026年に5,832件超になってた

まず数字を出す。2026年4月時点で、クラウドワークスの「AI関連案件」は累計5,832件を超えてる。

2023年11月から2024年にかけて、生成AI関連の契約件数は前年比8.4倍に急増した。さらに、AI案件の単価は1.8倍に上昇してる。

> **クラウドワークスAI案件の成長率**
> 件数 2024年比 8.4倍／単価 1.8倍／2026年累計 5,832件超

もう一つ大事な数字がある。

生成AIを副業で使っている人の年間副収入は平均119.1万円。使ってない人の約2倍。月換算で約10万円の差がついてる。

これだけ見ると「AI副業チャンスでは？」と思う。

実際チャンスではある。ただ、5,832件の中身を見ると、全部が全部「非エンジニアの副業初心者」に向いてる案件じゃない。

ここを見落とすと、文字単価300円のAIライター地獄に突っ込む。

## 5,832件の内訳は、実はライターばかりじゃない

クラウドワークスで「AI」を検索すると、上位に出てくるのは確かにライティング案件が多い。でも実際の内訳をざっくり分解するとこうなる。

- ① AIライティング（3,000件以上）— 激戦区、単価0.3〜1円
- ② 業務自動化スクリプト（増加中）— 単価1万〜6万円、競合少
- ③ WebアプリUI／LP制作（AI活用型）— 単価3万〜10万円
- ④ ChatGPT プロンプト作成・カスタムGPTs — 単価5千〜3万円
- ⑤ データ分析・リサーチ代行 — 単価1万〜5万円

全部ひっくるめて5,832件。そのうち半分以上は①のライティング系で、競合が集中してる。

逆に言うと、残りの約2,800件は競合がそれほど激しくない。

文系大学生で、プログラミング経験ゼロのわたしが選んだのは、意外にも②と③だった。

## 文系大学生のわたしが実際に選んだのは「業務自動化」だった

業務自動化スクリプト案件を選んだ理由は3つ。

1. 単価が段違いに高い（1件1万5千円〜6万5千円）
2. 継続案件につながりやすい
3. Claude Code との相性が最高だった

結果として、業務自動化3件 + WebアプリUI案件1件で、2ヶ月目に月14万円に到達。月4件ペース。

ライター案件で同じ金額を稼ごうとしたら、約466,000文字書く必要がある。現実的じゃない。

## 文系でも業務自動化案件が取れた理由

コードを「書く」場面はほぼなかった。やってるのは「AIに頼む」「出てきたものを確認する」だけ。

Excel 業務自動化案件の流れ:

1. 案件詳細を Claude にコピペして要件整理
2. Claude が作った確認文でクライアントに要件確認
3. Claude Code に実装を指示
4. 動作確認して納品

AI時代の副業で求められるスキルは「コードが書ける」より「AIに頼めて、出てきたものが合ってるか判断できる」。それなら文系でもできる。

## ライター以外の案件を見つけるコツ

検索キーワードを変える。

- 業務自動化系: Excel自動化／Google Apps Script／Python スクリプト
- Webアプリ系: LP制作／管理画面／予約システム
- プロンプト系: ChatGPT プロンプト／カスタムGPTs

予算1万円以上で絞ると低単価案件が消える。「継続できる人募集」案件を優先すると継続率上がる。
