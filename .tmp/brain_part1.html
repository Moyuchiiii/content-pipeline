FAQ

プログラミング経験ゼロでも業務自動化案件は取れますか

取れます。わたし自身、クラウドワークスに登録した時点でプログラミング経験はほぼゼロでした。Claude Code に要件を日本語で伝えると、コードは Claude Code が書いてくれます。やることは「クライアントと要件を整理する」「出てきたコードが動くか確認する」の 2 つです。

Claude / Claude Code は有料プランが必要ですか

無料の Claude（claude.ai のブラウザ版）でも、案件分析・応募文作成まではできます。ただし実装フェーズで使う Claude Code は月 20 ドルの Pro プラン契約が実質必要です。1 件受注できれば、Pro プランの月額は十分カバーできる水準の単価が業務自動化領域の相場です。

AI 使用を明記しないと不正になりますか

クラウドワークスは「AI 使用 OK 案件」「AI 使用 NG 案件」「AI 使用可否未記載案件」の 3 種類があります。「AI 使用 NG 案件」に該当する案件に AI 生成物をそのまま納品するのは規約違反です。「AI 使用 OK」「未記載」の案件では、AI を使ったと明記する義務はありません。ただし、プロポーザルで「AI を活用して効率化します」と公言する戦略は単価アップの交渉材料になる場合があります。

非エンジニアでも業務自動化案件の納品は本当にできますか

案件の難易度による、が答えです。「Excel のマクロで売上集計を自動化して毎週メール送信」のような要件が固まった案件なら、Claude Code に指示するだけで納品物が出来上がります。一方「既存システムの API を叩いて独自ダッシュボードを構築」のような要件が流動的な案件は、最初のうちは避けたほうが無難です。記事内で受ける案件・避ける案件の判定基準を細かく書きました。

note 版との違いは何ですか

note 版は「内訳分解の事実」と「非エンジニアが選ぶべき領域はどこか」までを書いた無料記事です。Brain 版はそれに加えて、応募文テンプレ 5 パターン全文・Claude 指示プロンプト 10 本全文・実案件 3 件の全工程ケーススタディ・検索キーワード集 30 個以上・継続案件化のチェックリストを同梱した実務用マニュアルです。記事の容量は note 版の約 6 倍です。
