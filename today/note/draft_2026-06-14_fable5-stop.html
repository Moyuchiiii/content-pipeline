朝起きて Claude を開いたら、いつものモデルが消えていた、なんてことありませんか？

2026-06-12 の夜、Anthropic の最新モデル Claude Fable 5 と Mythos 5 が、米政府の輸出規制で全部止まった。

X のタイムラインを朝開いたら、AnthropicAI のメガバズが流れてきて、正直「副業どうすればいいんだろう」とちょっと焦った。

でも結論から書くと、副業の Pro $20 派にとって実害はほぼゼロだった。何が起きて、なぜ慌てなくていいか、整理しておく。

米政府の輸出規制で、Fable 5 と Mythos 5 が一晩で止まった

2026-06-12 の米東部時間で午後 5:21、Anthropic は米政府から輸出規制の指令を受けた。日本時間だと 6/13 の朝にあたる。

対象は「すべての外国人」。米国内にいる外国人も、海外にいる外国人も、Anthropic で働いてる外国籍の社員も、全員 Fable 5 / Mythos 5 へのアクセス不可になった。

そして結果として何が起きたか。

Anthropic は全顧客に対して、Fable 5 / Mythos 5 を disable した。

外国人だけ止めるのが運用的にむずかしいから、いったん全員止めた。Anthropic 公式の声明にはっきり書いてある。

副業 Pro $20 派は、Opus 4.8 でいつも通り動ける

Claude Devs 公式の説明だと、Fable 5 が止まった後は「自分が選んでいたデフォルトモデル、もしくは Opus 4.8」に自動で切り替わる。

つまり、Pro $20 を払って副業の作業を Claude.ai と Claude Code でやってるわたしは、Opus 4.8 がデフォルトとして走る。

正直、これでほぼ実害ゼロだった。

Opus 4.8 は 5/28 に出た最新世代の Opus で、副業の応募文生成、CW 案件のコード書き、note のドラフト整理、全部いつも通り回せてる。

Fable 5 を意識して使ってた一部のユーザー以外、Pro $20 派にとっては「モデルが切り替わった」以上の体感差はなかった。

慌てなくていい理由は、Anthropic の立場にある

Anthropic 公式の声明を読むと、Anthropic 自身も「これは誤解」と立場を表明している。

米政府の発令文には、具体的な国家安全保障の理由が書かれていない。Anthropic の理解では、米政府が「Fable 5 をジェイルブレイクする方法を見つけた」と思い込んでいる、ということらしい。

でも Anthropic は、Fable 5 のリリース前に、米政府・英国 AISI・複数の第三者機関・内部チームと、累計で数千時間の red-team を実施している。Fable の safeguards は過去にデプロイされた他のどのモデルより substantially more effective だった、と公式が明言してる。

つまり、ジェイルブレイクの脅威としては他社モデルでも普通にできる軽微なやつである可能性が高い、というのが Anthropic の見方。

「access の復元に向けて働きかけ中」とも書いてある。

長期的に Fable 5 が完全消滅する話ではなく、当面は止まる、というニュアンスで読み取れる。

こうやってモデルが急に変わっても、副業の作業がそのまま回るのは、わたしが「Pro $20 で何ができるか」を 2 ヶ月かけて積み上げてきたから。同じ場所から始めたわたしがどう月14万まで来たかは、メイン記事にまとめた。

副業派が今やるべきことは、たぶん「何もしないこと」

Fable 5 を使ってない人、つまり Pro $20 派の多数派は、本当に何もしなくていい。Opus 4.8 にフォールバックされた状態で、いつもの作業を続けるだけ。

Fable 5 を使ってた人だけ、Claude.ai と Claude Code のモデル選択画面を 1 回確認して、Opus 4.8 か Sonnet 4.6 がデフォルトに入ってるかチェックすればいい。

このニュース、X や海外メディアではちょっと大ごとに見える書き方もあるけど、副業の現場で実際に何かが止まったかというと、止まってない。

慌てて Gemini や ChatGPT に乗り換えると、副業ジャンルごとに作り込んだ CLAUDE.md・スキル・プロンプトをまた一から組み直すコストが発生する。今は静観が一番安いと思う。

同じ場所で詰まってる君へ、3つだけ置いていく

1. Claude.ai または Claude Code でいったんモデル選択画面を開いて、Opus 4.8 が選べるか確認する。これだけで実害ゼロを確かめられる

2. Fable 5 を意識して使ってなかったなら、今日の作業は普段通りで OK。慌てて他社モデルに切り替えると失うものの方が大きい

3. 「Fable 5 が消えた」ニュースだけ追わずに、Anthropic 公式 anthropic.com/news の続報を 1 週間に 1 回チェックする。Anthropic が access 復元に動いてる以上、再開される可能性は十分ある

これだけで、わたしが今朝モヤモヤしたあの時間は飛ばせる。

速報ニュースのたびに揺れずに済むのは、副業のジャンルが先に決まってて、ツール側の変化に振り回されない構造を作っておいたから。Pro $20 派のわたしが副業ゼロから月14万まで来た手順は、メイン記事に書いた。
